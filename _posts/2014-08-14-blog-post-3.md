What exactly does single cell multiome processing entail?
======
Preprocessing
======
So we start off with cell ranger arc cloud where we take our raw data and process it by taking the fastq from the single cell rna-seq and single cell atac-seq and aligning it with the transcriptome reference. The transcriptome reference in my case is Crotalus viridis reference genome in which we take the Cvv_566 I1,R1,R2,R3 from Atac seq and the I1,I2,R1,R2 from the multiome gene expression. I personally used Cell Ranger Arc Count v2.0.2 to analyze it. It was pretty easy to do due to good UI.
